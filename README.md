# Amazon Sales Analysis Dashboard
This project presents an interactive **Amazon Sales Analysis Dashboard** developed using Microsoft Power BI. The dashboard is designed to analyze sales performance, product performance, customer reviews, and sales trends across different time periods and product categories.
The project demonstrates practical skills in data cleaning, data analysis, DAX, data modeling, and business intelligence visualization.

## Tools and Technologies
* Microsoft Power BI
* Microsoft Excel
* DAX (Data Analysis Expressions)
* Data Modeling

## Data Preparation
The dataset was obtained from a YouTube tutorial dataset description and was used for educational and portfolio purposes.
Microsoft Excel was used to clean and prepare the raw dataset before importing it into Power BI. The data preparation process included:
* Identifying and handling missing or inconsistent values
* Removing unnecessary data
* Standardizing data where required
* Preparing the dataset for analysis and visualization

## Data Analysis
After cleaning the dataset, it was imported into Power BI for further analysis. DAX was used to create calculated measures and key performance indicators, including:
* Year-to-Date (YTD) Sales
* Quarter-to-Date (QTD) Sales
* YTD Products Sold
* YTD Reviews
* Sales performance by product category
* Product-level sales analysis

## Dashboard Features
The dashboard provides an interactive view of:
* Overall sales performance
* Monthly sales trends
* Weekly sales trends
* Product category performance
* Product-wise sales performance
* Product review analysis
* Quarterly performance
* Year-to-Date performance
Interactive filters and slicers allow users to explore the data based on different categories and time periods.

## Project Workflow
The overall workflow followed for this project was:

**Raw Dataset → Data Cleaning in Excel → Data Import → Data Modeling in Power BI → DAX Calculations → Dashboard Development → Data Analysis**
